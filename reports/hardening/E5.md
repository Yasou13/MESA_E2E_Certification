PROBLEM REPRODUCED: CONFIRMED. The preserved retrieval and answer reports both
declare PASS while executable evaluation of their published metrics fails B10
and B12, and the historical verdict still declares `CERTIFIED` / `PASS`.

ROOT CAUSE: No executable component separated successful execution from gate
quality or enforced the invariant that every hard gate must PASS.

FILES CHANGED: Gate/verdict models and engines, frozen gate configuration,
gate/verdict and historical-contradiction tests, config documentation, and this
phase report.

TESTS ADDED/CHANGED: Recall, single-hop recall, MRR, REL complete-evidence,
answer hard-gate failure, execution/gate separation, missing/invalid/drifted
freeze, missing mandatory evidence, unverified gate, invalid lifecycle,
complete hard-pass set, and preserved historical contradiction.

OLD BEHAVIOR: Report `status=PASS` could coexist with metrics below normative
thresholds and final generic `PASS` / `CERTIFIED`.

NEW BEHAVIOR: Every gate emits `execution_status` and `status` separately with
required/observed values, reason, and evidence. Final verdict uses only exact
Profile B terminal statuses. Any hard FAIL yields `PROFILE_B_FAIL`; missing or
unverified prerequisites block; SHA drift yields `INVALIDATED_CODE_CHANGE`;
only a complete mandatory PASS set can yield `PROFILE_B_PASS_NATIVE`.

FALSE-PASS CANARIES: Each B10 threshold independently failing, B12 failing,
missing gate, unverified gate, missing artifact, missing freeze, invalid
freeze, SHA drift, invalid lifecycle, and duplicate gate IDs.

FALSE-FAIL CANARIES: All mandatory hard gates PASS with valid freeze/lifecycle
and complete artifacts yields `PROFILE_B_PASS_NATIVE`; a supplemental
diagnostic failure does not override the complete hard PASS set.

FREEZE / ORACLE IMPACT: Verdict consumes E4 freeze verification and cannot
bypass invalidation. It neither reads nor injects oracle fields.

BACKWARD COMPATIBILITY: Historical generic PASS is preserved as evidence but
is not an accepted v2 terminal status. Thresholds are unchanged from the
current agent-pack contract.

MESA CONTRACT DEPENDENCY: NONE

METHODOLOGY DECISION REQUIRED: The current approved B12 hard-gate contract is
retained. Changing B12 to supplemental remains
`HUMAN_METHODOLOGY_DECISION_REQUIRED` and was not performed.

FOCUSED TEST RESULT: 14/14 E5 and historical contradiction tests passed.

RELEVANT SUITE RESULT: 45/45 pytest tests and optimized 17/17 self-tests passed.

KNOWN LIMITATIONS: B0–B9 and B11–B14 artifact producers/evaluators are supplied
by their respective phases or future MESA synchronization; absent gate results
remain non-PASS by design.

WHY SAFE TO CONTINUE: The engine preserves existing thresholds and only
prevents verdict inflation; it cannot create PASS from missing, failed,
unverified, or drifted evidence.
