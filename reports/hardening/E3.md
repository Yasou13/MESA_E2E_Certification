# E3 — Answer Scorer v2

PHASE: E3

STATUS: GREEN

BASE SHA: `574f158`

PHASE COMMIT: commit containing this report (`e2e-03`)

PROBLEM REPRODUCED: CONFIRMED. The live scorer did not consume
`required_facts`, escaped regex metacharacters into literals, accepted an
abstention marker as a substring, and could PASS keyword-bearing denial or
unstructured additional material.

ROOT CAUSE: Free-text keyword presence was treated as fact satisfaction and
the response schema did not expose material claims for deterministic grading.

FILES CHANGED: Answer pattern/claim schemas, answer scorer, self-test fixtures,
E3 canaries, and this phase report.

TESTS ADDED/CHANGED: All mandatory facts, literal vs regex, all_of, any_of,
denial with expected keyword, strict NO_ANSWER, unsupported extra material,
forbidden claim, context-external citation, unknown identity, and missing
fact-pattern ambiguity.

OLD BEHAVIOR: One matching keyword could establish `facts_satisfied`; appended
substantive text plus `YETERSİZ KANIT` could PASS; regex-like patterns were
silently literal; required facts did not participate.

NEW BEHAVIOR: Every required fact needs an explicit fact-linked pattern,
structured claim, frozen source link, and in-context citation. Pattern mode is
explicit (`literal`, `regex`, `all_of`, `any_of`). Ambiguous coverage is
`UNRESOLVED`, never PASS. NO_ANSWER must exactly equal the configured marker
and carry no citations or claims.

FALSE-PASS CANARIES: Missing second fact, denial with required keyword,
substantive answer plus abstention, extra unstructured material, forbidden
claim, fabricated/unknown evidence, and citation outside context.

FALSE-FAIL CANARIES: Regex and literal semantics are separately tested;
all_of/any_of behavior is explicit; a fully structured source-linked answer
passes; exact canonical abstention passes.

FREEZE / ORACLE IMPACT: Pattern and claim schemas are deterministic scorer
inputs for later freeze. GT remains grader-only and is not introduced into an
execution request.

BACKWARD COMPATIBILITY: Legacy string patterns are accepted only as explicit
literal patterns without fact links. Such inputs cannot manufacture PASS for
items with required facts and therefore become `UNRESOLVED` until migrated.

MESA CONTRACT DEPENDENCY: NONE for scorer correctness. Final evidence-ID
adapter alignment may require WAIT_FOR_MESA_PHASE_1.

METHODOLOGY DECISION REQUIRED: HUMAN_METHODOLOGY_DECISION_REQUIRED — whether
grounded answer quality remains a HARD Profile B gate or becomes SUPPLEMENTAL.
This phase does not choose or change that policy.

FOCUSED TEST RESULT: 10/10 E3 scorer canaries passed.

RELEVANT SUITE RESULT: 26/26 pytest tests and optimized 17/17 self-tests passed.

KNOWN LIMITATIONS: Denial detection is deterministic and conservative rather
than a semantic judge. Free text that cannot be fully represented by explicit
claims remains non-PASS by design.

WHY SAFE TO CONTINUE: The scorer only removes unsupported confidence; it does
not change thresholds, gate hardness, historical evidence, or the final
certification methodology.
