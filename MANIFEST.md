# MESA Profile B Certification Repository Manifest

## Certification identity

- Name: MESA Profile B — Legal End-to-End Integration & Retrieval Certification
- Test ID: `MESA-PROFILE-B-LEGAL-E2E`

## Repository roles

### agent-pack/

Authoritative instructions, policies, prompts and runbooks used by the
autonomous certification agent.

### config/

Runtime and benchmark configuration.

Configuration used for the TEST benchmark must be frozen before evaluation.

### datasets/

Corpus manifests and immutable dataset references.

Secrets and mutable runtime storage must never be committed here.

### ground-truth/

Independent DEV and TEST ground truth.

Ground truth must be created and frozen without using MESA retrieval results.

### harness/

Certification harness, scorers, validators and deterministic test utilities.

### evidence/

Evidence generated by certification runs.

Failed certification runs must never be silently deleted.

### runs/

Per-run state and artifacts identified by RUN_ID.

### reports/

Certification reports and final verdicts.

### scripts/

Operational and reproducibility scripts.

## Main repositories under test

This repository does not replace the product repositories.

The certification agent operates against separate checkouts of:

- MESA
- MESA_Data

Their exact commit SHA values must be recorded for every certification run.
