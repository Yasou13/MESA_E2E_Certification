# MESA Legal E2E Certification

**Official certification name:**  
MESA Profile B — Legal End-to-End Integration & Retrieval Certification

**Test ID:**  
`MESA-PROFILE-B-LEGAL-E2E`

This repository contains the autonomous end-to-end certification suite for
MESA and MESA_Data.

Profile B validates:

- Native MESA_Data → MESA ingestion
- NVIDIA Nemotron embeddings
- NVIDIA GPT-OSS extraction
- MESA V4 retrieval
- Kùzu graph retrieval
- Graph ablation
- Legal retrieval quality
- Ground-truth scoring
- Grounded answer generation
- Tenant isolation
- Provenance
- Idempotency
- Restart persistence
- Runtime/provider integrity
- Reproducible evidence

## Certification rule

A Profile B PASS does not by itself mean that MESA is fully MVP certified.

Final MVP certification requires the complete MESA certification program.
